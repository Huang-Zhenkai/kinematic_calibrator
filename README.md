# 🎯 kinematic-calibrator

> **推导误差雅可比不用再掉头发，排查冗余参数像魔法一样自动，标定并联机构像串联一样无痛。**

`kinematic-calibrator` 是基于 `lieink` (Local POE 模块) 打造的**自动化运动学标定引擎**。

如果你曾经被运动学标定折磨过，你一定懂这些痛：手动推导 DH 误差模型推到眼花、辨识矩阵因为冗余参数秩亏导致解爆炸、好不容易搞定了串联臂，老板又让你去标定含有各种不可测被动关节（UMP）的复杂并联机构……

这个库就是为了终结这些噩梦而生的。它利用**局部指数积（Local POE）**公式，能**全自动**为任意串联、并联机构提取最小独立误差参数集，你只需要喂给它传感器数据，剩下的脏活累活全交给底层算法。

---

## ✨ 为什么选择 Local POE（局部指数积）？

在运动学标定中，模型的选择决定了你掉头发的速度：
- **DH / MDH 模型**：局部物理意义明确，但建系规则极其死板，一旦遇到平行轴就会遭遇臭名昭著的奇异性问题，导致模型失效。
- **全局 POE 模型**：数学极其优雅，无奇异，但所有旋量参数都基于基坐标系。一旦算出了误差，你根本不知道这是第 3 轴装歪了，还是第 4 轴加工错了。

**Local POE 是标定的终极答案。**
它在相邻关节之间建立局部旋量，既保留了 POE 优雅的指数映射（彻底告别几何奇异性），又让每一个误差参数都死死绑定在具体的物理关节上（完美的局部物理意义）。本库正是以此为基石，让误差辨识既稳定，又具备实际的工程指导意义。

## 🎨 核心设计理念

### 1. 自动最小化建模 —— 告别“矩阵奇异”的噩梦
你不需要手动指定哪些参数该辨识、哪些参数该剔除。在实例化标定器时，它会在后台默默完成一系列硬核操作：
- **局部旋量降维**：自动识别 R 关节（保留 4 个独立误差参数）和 P 关节（保留 2 个独立误差参数）。
- **并联拓扑冗余分析**：基于你赋予 `lieink` 的关节语义（UMP / MP / A），自动扫描支链拓扑。例如发现 `Two adjacent unmeasurable prismatic joints` 结构时，自动剔除杆件法向自转冗余。
- **运动学构型奇异剔除**：引入 SVD 奇异值分解，通过随机采样探测因特定构型导致的隐藏冗余，并自动生成分离算子。

**结果就是：送进求解器的雅可比矩阵，天生就是满秩的。**

### 2. 串并联大一统 —— 标定并联机构像串联一样简单
得益于 `lieink` 优秀的底层抽象，在这里标定串联臂和并联机构是一样的体验。
对于并联机构，引擎会自动将其拆解为多条支链，利用被动关节空间速度雅可比的零空间（Null space）将末端位姿误差投影到关节空间，自动协调闭环约束进行多支链同步标定。无需你手动推导复杂的闭环约束偏导数。

### 3. 求解器解耦 —— 我们造枪，你来填弹
标定算法千千万（最小二乘、Levenberg-Marquardt、岭回归等），`kinematic-calibrator` 坚决不越俎代庖。
我们将**物理建模**与**数值求解**完全解耦：本库负责求取误差模型、投影零空间、消除冗余参数，而你只需要在调用时传入一个自己喜欢的纯数值 Solver 函数即可。你可以随时换上更高级的鲁棒优化算法，而不需要改动任何物理建模代码。

### 4. 时光机（History Tracking）—— 看着误差一步步收敛
标定是一个迭代过程。引擎内置了历史记录容器，它会记录每次迭代后生成的全新机构对象。配合评估方法，你可以轻松提取并绘制误差收敛曲线，一切尽在掌握。

## 🚀 工作流概览

使用本库进行标定的典型工作流非常清爽，无需手写繁琐的循环与偏导数：

1. **准备模型**：使用 `lieink` 搭建你的标称串联或并联机构模型（只需确认关节语义，如哪些是被动不可测关节）。
2. **实例化标定器**：将模型传入 `KinematicCalibrator`，此时底层的自动最小化建模已经瞬间完成。
3. **准备数据与求解器**：准备好指令关节角、实际末端位姿（如激光跟踪仪数据），并定义一个简单的数值求解器（例如基于 `numpy.linalg.lstsq`）。
4. **一键迭代**：调用 `calibrate` 方法，引擎会自动计算误差对数映射、映射伴随矩阵、剔除冗余，并调用你的求解器更新模型。
5. **评估与导出**：通过 `evaluate` 方法查看位置和姿态的收敛精度，并直接提取高精度的全新机构模型用于实际控制。

## 🏗️ 幕后黑科技：误差模型是怎么建立的？

在核心的迭代源码中，参数的更新逻辑可以用下面这行代数方程来概括：

$$\Delta \boldsymbol{p} = \mathrm{Solver}(\boldsymbol{\Gamma} \boldsymbol{\Delta} \boldsymbol{S}, \boldsymbol{e})$$

这完美体现了 Local POE 标定理论的代码化艺术：
- $\boldsymbol{e}$：基于李代数严格计算的对数映射误差。在并联机构中，它已被零空间投影巧妙地过滤掉了不可测被动关节的干扰。
- $\boldsymbol{\Gamma}$：基于局部位姿计算出的伴随矩阵大集合，负责将 Local POE 坐标系下**局部的、具有物理意义的加工装配误差**，精确映射到末端操作空间。
- $\boldsymbol{\Delta}$：结构偏导数矩阵，反映局部旋量微小摄动对位姿的影响。
- $\boldsymbol{S}$：**全库的灵魂（分离算子 Separation Operator）**。这是一个自动生成的列满秩选择/正交化矩阵，它像滤网一样滤掉了所有几何与拓扑冗余参数，确保最终的雅可比矩阵列列独立。
